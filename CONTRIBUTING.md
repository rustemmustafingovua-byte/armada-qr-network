# Contributing

Thanks for your interest in contributing!

## Development

```bash
git clone https://github.com/rustemmustafingovua-byte/armada-qr-network.git
cd armada-qr-network
npm install
npm test
```

## Guidelines

- Follow the existing code style.
- Add tests for new behavior.
- Open an issue before large changes.
