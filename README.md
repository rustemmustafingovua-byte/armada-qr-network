## 🚀 Быстрый старт

```bash
git clone https://github.com/rustemmustafingovua-byte/armada-qr-network
cd armada-qr-network && npm install
npm start
# → http://localhost:3000
```

---

## 🎯 Демо

```bash
curl -X POST -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"My Link","content_type":"link","target_url":"https://example.com"}' \
  https://your-site.com/api/v1/qr
```

## 💰 Монетизация

- **Enterprise hosting**: развёртывание платформы для корпоративных клиентов
- **Custom QR campaigns**: создание промо-кампаний с QR-кодами под заказ
- **Analytics SaaS**: продажа доступа к аналитике сканирований
- **Integration services**: интеграция QR-платформы в CRM и маркетинговые инструменты
